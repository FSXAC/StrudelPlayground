# StrudelPlayground
My Strudel projects

## Examples

Paste any of these into [strudel.cc](https://strudel.cc) and hit play.

| File | Vibe |
| --- | --- |
| `examples/deep-house.strudel` | 122bpm deep house, rhodes stabs, warm pad |
| `examples/festival-edm.strudel` | 128bpm big room EDM, supersaws, sidechain, build/drop toggle |
| `examples/lofi-rainy-day.strudel` | 82bpm lo-fi hip hop, swung crunchy drums, jazzy keys |
| `examples/liquid-dnb.strudel` | 174bpm liquid DnB, chopped break, reese bass |
| `examples/acid-warehouse.strudel` | 135bpm acid techno, 303-style squelch, rumble kick |
| `examples/ambient-drift.strudel` | Slow ambient, drifting pads and random celesta sparkles |

## AI examples

The `ai/` folder has AI-written examples: an expanded version of my 1980s loop, plus 11 genre sketches that each teach a few Strudel techniques. See [`ai/README.md`](ai/README.md) for the list.
